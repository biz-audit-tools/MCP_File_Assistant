# Перечень скриншотов для сдачи

Скриншоты нужно сделать вручную в Codex. Не показывайте полный личный `config.toml`, токены, ключи, пароли и другие пользовательские настройки.

## 1. Подключённый сервер Filesystem MCP

Показать экран со списком MCP-серверов, где видны:

- сервер `filesystem`;
- статус подключения;
- доступные инструменты Filesystem MCP или часть их списка.

Личный путь можно обрезать или замаскировать, если преподавателю он не нужен.

## 2. Получение списка десяти документов через MCP

Показать сообщение с вызовом `mcp__filesystem__list_directory` для папки `documents` и результатом, содержащим десять DOCX-файлов. В кадре должно быть видно название вызванного MCP-инструмента.

## 3. Создание CSV-отчёта с четырьмя договорами

Показать результат поиска `contract_*`, размеры четырёх файлов и подтверждение записи CSV через `mcp__filesystem__write_file`. Дополнительно можно открыть `reports/contracts_with_mcp.csv`, чтобы были видны заголовок и четыре строки.

## 4. Редактирование тестового файла через MCP

Показать diff инструмента `mcp__filesystem__edit_file`, где строка:

```diff
-Сумма: 100000 руб.
+Сумма: 150000 руб.
```

Желательно включить в кадр контрольное чтение через `mcp__filesystem__read_text_file`.

## 5. Сравнение результатов с MCP и без MCP

Показать оба файла:

- `reports/contracts_without_mcp.csv`;
- `reports/contracts_with_mcp.csv`.

В кадре должны быть видны совпадающие заголовки и четыре строки данных. В подписи к скриншоту указать, что возможное различие размеров связано с `LF`/`CRLF` и завершающим переводом строки, а не с табличными данными.

## Перед отправкой

- Проверьте, что на скриншотах нет токенов, паролей и ключей API.
- Не показывайте полный файл `C:\Users\<пользователь>\.codex\config.toml`.
- Не включайте служебные каталоги, vault-файлы и временные файлы.
- Не заявляйте о преимуществе MCP по скорости: отдельного измерения не было.
