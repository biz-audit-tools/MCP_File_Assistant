# Краткое описание проекта MCP File Assistant

Проект подготовлен к уроку 3.2 «Использование MCP-серверов» и демонстрирует работу Codex с локальными файлами через `@modelcontextprotocol/server-filesystem`.

## Что было проверено

1. Filesystem MCP получил список из десяти тестовых DOCX-файлов, нашёл четыре договора по префиксу `contract_`, определил их размеры и сформировал CSV-отчёт.
2. Через MCP создан и дважды прочитан `mcp_experiment.txt`; сумма точечно изменена со 100 000 до 150 000 рублей, а две первые строки сохранены.
3. Один и тот же CSV-отчёт создан встроенными средствами Codex и через Filesystem MCP. Табличные данные совпали; технически файлы отличаются окончаниями строк и общим размером.
